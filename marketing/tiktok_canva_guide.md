# TikTok フォトモード × Canva一括作成ガイド

## 概要

Canvaの「一括作成（Bulk Create）」機能を使って、TikTokフォトモード用のカルーセル画像を自動生成する手順です。

---

## STEP 1: Canvaでテンプレートを作る（1回だけ）

### テンプレート設定
- **サイズ**: 1080 × 1920 px（TikTok/Reels縦型）
- **背景**: グラデーション（#0ea5e9 → #0284c7 の水色系）
- **フォント**: Noto Sans JP Bold

### テンプレートに配置する要素（テキストボックス）

#### スライド用テンプレートA:「タイトルスライド」
```
┌─────────────────────┐
│                     │
│    [TITLE]          │  ← 大きめ白文字（36-48pt）
│                     │
│    [SUBTITLE]       │  ← やや小さめ白文字（20-24pt）
│                     │
│    @たべなび         │  ← アカウント名（固定）
│                     │
└─────────────────────┘
```

#### スライド用テンプレートB:「データスライド」
```
┌─────────────────────┐
│                     │
│    [HEADING]        │  ← 見出し白文字（28-32pt）
│                     │
│  ┌───────────────┐  │
│  │  [DATA1]      │  │  ← 白い角丸カード
│  │  [VALUE1]     │  │    メニュー名 + 数値
│  └───────────────┘  │
│  ┌───────────────┐  │
│  │  [DATA2]      │  │
│  │  [VALUE2]     │  │
│  └───────────────┘  │
│  ┌───────────────┐  │
│  │  [DATA3]      │  │
│  │  [VALUE3]     │  │
│  └───────────────┘  │
│                     │
│    @たべなび         │
└─────────────────────┘
```

#### スライド用テンプレートC:「CTA（最終スライド）」
```
┌─────────────────────┐
│                     │
│   外食の栄養、       │
│   もう迷わない。     │
│                     │
│   [CTA_TEXT]        │  ← 「たべなび で検索」等
│                     │
│   tabenavi.jp       │
│                     │
│    @たべなび         │
└─────────────────────┘
```

### テンプレートの作り方
1. Canva（canva.com）を開く
2. 「カスタムサイズ」→ 1080 × 1920 px
3. 背景をグラデーションに設定
4. テキストボックスを配置
5. 各テキストボックスを右クリック → 「データに接続」で変数名を設定

---

## STEP 2: CSVをアップロードして一括作成

1. Canvaの左メニュー「アプリ」→「一括作成」を選択
2. 「CSVをアップロード」をクリック
3. marketing/tiktok_slides_data.csv をアップロード
4. 各テキストボックスにCSVの列を紐づける
5. 「ページを生成」をクリック → 全スライドが自動生成！
6. まとめてダウンロード（PNG）

---

## STEP 3: TikTokに投稿

1. TikTokアプリを開く
2. 「＋」→ 右下「アップロード」
3. 生成した画像を複数選択（1投稿につき5〜8枚）
4. 「フォトモード」を選択
5. キャプションを入力（CSVのcaption列からコピペ）
6. ハッシュタグを追加
7. 投稿！

---

## 補足: Instagramリールも同じ画像でOK

TikTokフォトモードで作った画像はそのままInstagramのカルーセル投稿にも使えます。
サイズも同じ1080×1920pxなので、1回の制作で2プラットフォームに投稿可能。
