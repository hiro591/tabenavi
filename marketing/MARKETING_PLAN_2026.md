# たべなび マーケティング戦略 2026（最終版）

## 核心の洞察

**たべなびの本当の競合は、チェーン店の公式サイトにある栄養成分PDFである。**

あすけんでもカロミルでもない。「吉野家のPDFを開いて、小さいスマホ画面で
スクロールして、メニュー名を探して、カロリーを確認して、別の店のPDFも開いて
比較して...」この10分間のストレスが、たべなびが解決する問題。

つまり「たべなびを知ってもらう」必要はない。
**「PFCを調べたい瞬間」にたべなびが存在していればいい。**

マーケティングの問いは「どうやって認知を広げるか」ではなく、
**「意思決定の瞬間にどうやって存在するか」**。

---

## 戦略の全体像: 4レイヤー

```
Layer 4: 権威構築（3ヶ月目〜）
  四半期レポート、検証バッジ → インフルエンサーが自分から来る

Layer 3: プログラマティックSEO（2ヶ月目〜）
  自動生成ページ数千枚 → 検索からの永続流入

Layer 2: データ流通（1ヶ月目〜）
  埋め込みウィジェット → 他サイトに常駐して働く

Layer 1: 意思決定の瞬間に存在する（今日から）
  ジムQRポスター、フォーラム回答 → 最初の100人
```

**下から積み上げる。上のレイヤーは下が機能してから。**

## Layer 1: 意思決定の瞬間に存在する（Day 1-30）

### 1A. ジムQRポスター

「外食で迷ったら、ここで検索。」

A4ポスター1枚。QRコードで tabenavi.jp へ。
コンビニで100枚印刷（約¥1,000）。

都内のジム20店舗（Anytime Fitness、JOYFIT、Gold's Gym等）の
コミュニティ掲示板に掲示。許可は必要だが、無料の情報ポスターを断るジムはほぼない。

**なぜ効くか:** ジムに来る人 = PFCを気にする人。ジムを出た後にランチを探す。
その瞬間にQRコードが目に入る。これが「意思決定の瞬間への存在」。

予想獲得: 20店舗 × 15-20スキャン = **300-400人**（3ヶ月間累計）

### 1B. フォーラムでの「外科的」回答

コンテンツカレンダーではない。質問が存在する場所で、質問に答える。

**場所:**
- Yahoo!知恵袋（「吉野家 ダイエット メニュー」等の質問）
- Reddit r/japanlife, r/fitness（英語圏の日本在住者）
- 5ch 筋トレ板・ダイエット板
- X上の「外食 タンパク質」「チェーン店 カロリー」等のツイート

**やり方:**
質問に対して、具体的な栄養データで回答する。
「吉野家なら牛丼小盛(P17g/398kcal/¥398)がおすすめです。
 全メニューのPFC比較はこちら → tabenavi.jp」

スケジュールではなく、質問があるときだけ。1日10-15分。
各回答は永久にインデックスされ、永久に流入を生む。

予想獲得: **100-200人**（3ヶ月間累計）

### 1C. X「タンパク質コスパランキング」投稿

作成済みのインフォグラフィックを投稿。ピン留め。

```
外食でタンパク質を取りたい人へ。

20チェーン店、500メニューを全部調べて
「1円あたりのタンパク質」でランキングにした。

1位は意外にもマクドナルド。
エグチ ¥200 で P20.7g。

全チェーンのPFCを検索 → tabenavi.jp

#筋トレ飯 #外食ダイエット
```

この1投稿で反応を見る。バズったフォーマットだけを繰り返す。
30日カレンダーは作らない。データで判断する。

## Layer 2: データ流通（Day 15-60）

### 核心: データを閉じ込めない。流れさせる。

たべなびのデータ（500+メニューのPFC）は、Webサイトに閉じ込めている限り
「行かないと見れないもの」。これを「どこにでもあるもの」に変える。

### 2A. 埋め込みウィジェット

フィットネスブログ、ダイエットサイト、ジムのWebサイトに埋め込める
小さなHTMLウィジェットを作る。

**ウィジェット案:**
1. **チェーンPFCソーター** — 特定チェーンのメニューをP/F/C/価格でソート
2. **タンパク質コスパ計算機** — 予算を入れると最もP/¥が高いメニューを表示
3. **今日の高タンパク外食** — 日替わりでおすすめメニューを表示

全ウィジェットに「Powered by たべなび」のリンク付き。

**なぜ効くか（Typeform/Mailchimp/Calendlyの実証済みパターン）:**
- 埋め込みサイトごとに永続的なバックリンク（SEO効果）
- ウィジェットのユーザーが「たべなび」を知る（認知）
- 一度埋め込まれたら永久に働く（コスト0で永続集客）
- ブログ運営者にとって記事の価値が上がる（Win-Win）

**実装:** iframeまたはWeb Componentとして提供。
Next.jsの`/embed/[chain]`ルートで対応。

**シーディング:** 既に「吉野家 ダイエット」等の記事を書いているブログ10-20件に
直接連絡。「あなたの記事にライブPFCソーターを無料で埋め込めます。
記事の価値が上がります。」

予想獲得: **50-100人/月**（20サイトに埋め込み後、永続）

### 2B. 共有のOG画像（実装済み）

メニューを共有するとき、栄養データカードが自動生成される。
LINE/X/Instagramで共有すると、リッチなプレビューカードが表示される。
→ 友達がタップ → たべなびにアクセス。

## Layer 3: プログラマティックSEO（Day 30-90）

### 核心: 記事を「書く」のではなく、ページを「生成する」。

手動でSEO記事を書くのは線形。1記事1記事書く。
プログラマティックSEOは、データから自動でページを生成する。指数的。

### 成功事例:
| 企業 | 自動生成ページ数 | 月間オーガニック流入 |
|------|----------------|-------------------|
| Zapier | 70,000+ | 16.2M |
| Canva | 100M+ テンプレート | 100M+ |
| Wise | 通貨ペア全組み合わせ | 90M+ |
| NomadList（個人開発） | 24,000+ | 50K |

### たべなびのプログラマティックSEO

**3層のページ階層:**

```
Layer A: カテゴリページ（〜50ページ）
  /chains/fast-food — ファストフード全チェーンのPFC比較
  /goals/high-protein — 高タンパクメニュー全チェーン横断
  /areas/shinjuku — 新宿エリアの外食PFCガイド

Layer B: チェーン×目的ページ（〜200ページ）
  /chains/yoshinoya/high-protein — 吉野家の高タンパクメニュー
  /chains/mcdonalds/under-500kcal — マクドナルドの500kcal以下メニュー
  /chains/saizeriya/diet — サイゼリヤのダイエットメニュー

Layer C: ユーザー生成コンボページ（無限）
  /combos/yoshinoya-light-gyudon-salad — ユーザーが保存した組み合わせ
  → ユーザーが増えるほどページが増える → 検索流入が増える → ユーザーが増える
```

**Layer A + B は自動生成。** DBのデータからNext.jsのgenerateStaticParamsで
全組み合わせを生成。各ページにJSON-LD構造化データ（NutritionInformation）。

**Layer C はユーザー生成。** 食事の組み合わせを保存すると公開ページが
自動生成される。これがSEOフライホイール（Growth Loop 3）。

**なぜ効くか:**
- 「吉野家 高タンパク メニュー」「マクドナルド 500kcal以下」は実際に
  検索されているクエリ。現在は静的なブログ記事が上位。
  たべなびのページはDBから動的に最新データを提供するので、鮮度で勝つ。
- 200ページあれば、どれかは確実に検索上位に入る。全部が1位でなくていい。
- ユーザー生成コンボページは、書かなくても増え続ける。

**注意: 既存の46本のガイド記事は残す。** ただし、プログラマティックページが
同じクエリをカバーする場合、ガイド記事からプログラマティックページへの
内部リンクを追加して、データの鮮度で差別化する。

## Layer 4: 権威構築（Month 3〜）

### 4A. 四半期「外食PFCレポート」

データジャーナリズムとして、四半期ごとに外食栄養レポートを発行。

内容:
- 新メニュー追加の栄養トレンド（「サイゼリヤ、新メニュー12品の平均P+8%」）
- チェーン別タンパク質コスパの推移
- 値上げの影響（「100円あたりタンパク質量、前期比-12%」）
- 季節メニューの栄養分析

**はてなブックマークに投稿。** データドリブンなオリジナルリサーチは
はてブで定期的にバズる。1回のバズ = 10,000-50,000 PV。

**なぜ効くか:** これはマーケティング記事ではなく「一次情報源」。
フィットネスインフルエンサーが自分のコンテンツで引用する。
引用されるたびに、たべなびの権威が上がる。

### 4B. 「Verified by たべなび」バッジ

フィットネスインフルエンサーの栄養データ投稿を検証するサービス。
「この吉野家の栄養データは正しいです ✅ tabenavi.jp verified」

**なぜインフルエンサーが欲しがるか:**
フィットネス界隈は不正確な栄養データが溢れている。
「たべなび検証済み」のバッジがあれば、他のインフルエンサーとの差別化になる。
たべなびは「信頼性」を提供する。これはお金より価値がある。

→ インフルエンサーが自分からたべなびに来る。こちらから頼まない。

## 最後に

この戦略の本質は1文で言える:

**「データを流れさせろ。閉じ込めるな。」**

たべなびの500+メニューのPFCデータは、Webサイトに置いておくだけでは
「行かないと見れないもの」。これを、ジムの壁に、ブログの記事の中に、
Googleの検索結果に、LINEのグループチャットに、はてブのホットエントリに
流れさせる。データが流れるところにユーザーが生まれる。
