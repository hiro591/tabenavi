## #3 5ユーザー離脱理由DM【推奨文面・確定】

```
○○さん、たべなび作ったヒロです。使ってくれてありがとうございます！

正直に聞きたくて連絡しました。最近あんまり開いてないと思うんですが、何が物足りなかったですか？「ここがイマイチ」を一言でも教えてもらえると、めちゃくちゃ助かります。

スタンプ1個でもOKです🙏
```

**使い方**
- 冒頭 `○○さん` は各人の名前に置換。全員への第一弾はこれ（開発者本人の素直さが最も効く・返信ハードル最小）。
- 反応が薄い相手 → 番号選択式で再送:「①使い続けてる ②なんとなく開かなくなった ③他に乗り換えた ④最初から合わなかった」
- 完全離脱で気まずそうな相手 → 「責めるとかじゃなく純粋に知りたくて」とやわらかい最終リマインド。

## App Store Connect 提出手順

**アプリ名・サブタイトル・キーワード = 新バージョンの提出が必須（審査あり）**
1. App Store Connect → 対象アプリ → 最新バージョン（無ければ右上「＋バージョン」で作成）
2. 言語＝日本語の欄で、名前 / サブタイトル / キーワードを上記「推奨セット」に貼り替え（**キーワードはスペースを入れずカンマ区切りのまま**）
3. 必須項目を満たして「保存」→「審査へ提出」。反映は審査通過後。

**プロモーションテキスト = 新バージョン不要・審査なしで即時反映**
- 同じバージョン画面の「プロモーション用テキスト」欄に上記を貼って「保存」するだけ。リリース済みでもその場で差し替わる。

> ※ アプリ内の表示名（CFBundleDisplayName / capacitor.config の `たべなび`）はホーム画面のアイコン名なので、現状の「たべなび」のままでOK（長い名前にするとアイコン下で見切れる）。変更するのは**App Store掲載名**だけ。

## v1.2を既に審査へ提出済みの場合の適用手順

- **審査待ち(Waiting for Review)の場合**: 「審査から取り下げ」→ メタデータ(名前/サブ/KW)を編集 → **同じbuild 8のまま再提出**でOK（新ビルド不要）。
- **審査通過後の場合**: 次バージョン(v1.3)で適用。プロモテキストだけは今すぐ反映可。
- **メタデータ起因でリジェクトされた場合**: 新ビルド不要。KW欄をB案(店名なし)に差し替え、Resolution Centerで返信すれば再審査される。1サイクルの損失は通常1〜3日。
