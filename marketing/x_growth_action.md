# X (Twitter) 成長アクションプラン

## フェーズ0: フォロワー0 → 100人（最初の1-2週間）

### やること: 投稿ではなく「リプライ」に全力を注ぐ

Xのアルゴリズムは、フォロワーがいないアカウントの投稿をほぼ表示しない。
まずフォロワーを作る。フォロワーは「リプライ」から生まれる。

### Step 1: フォローする（今日中に50人）

以下のカテゴリから50人フォローする:

**筋トレ・フィットネス系（20人）**
- 検索: 「筋トレ 食事」「マクロ管理」「ボディメイク 外食」
- フォロワー1,000-10,000人のアカウントが狙い目（大きすぎると反応されない）

**ダイエット・食事管理系（15人）**
- 検索: 「ダイエット 外食」「カロリー管理」「あすけん」
- 実際にダイエット記録を投稿している個人アカウント

**パーソナルトレーナー（10人）**
- 検索: 「パーソナルトレーナー 食事指導」
- 都内のジムのトレーナーが多い

**筋トレ系インフルエンサー（5人）**
- フォロワー1万以上の有名アカウント
- 直接リプライしても反応は薄いが、彼らのフォロワーに見てもらえる

### Step 2: 毎日リプライ10件（最低2週間続ける）

**リプライのルール:**
- 「いいですね！」だけのリプライは無意味。データで価値を提供する
- たべなびの宣伝はしない。純粋に役立つ情報を返す

**リプライテンプレート:**

誰かが「今日のランチ、吉野家の牛丼食べた」と投稿したら:
→ 「牛丼並盛、実はP20gあるので意外と優秀ですよ！脂質が気になるなら小盛(P17g/488kcal)もコスパいいです 💪」

誰かが「ダイエット中に外食何食べればいいかわからん」と投稿したら:
→ 「サイゼリヤの若鶏のグリルがP35.3gで500円なので最強です。マクドナルドならエグチがP20.7gで200円。意外とファストフードも選び方次第ですよ」

誰かが「筋トレ後に何食べよう」と投稿したら:
→ 「ガストのミックスグリルがP45gで500円、コスパ最強です。牛丼チェーンならすき家の牛丼大盛がP30gで380円」

**ポイント:**
- 具体的な数字を必ず入れる（P○○g、○○kcal、¥○○○）
- 相手の投稿に合わせた内容にする（コピペ感を出さない）
- たべなびのリンクは貼らない（プロフィールにURLがあるので、興味を持った人は自分で見に来る）
- 1日10件、朝・昼・夜に分けて行う

### Step 3: プロフィールを「人」にする

現在のプロフィール:
❌ 「外食しながらカラダづくり。20チェーン・500メニューの栄養データが無料で使えるWebアプリ「たべなび」の公式アカウントです。」

これは「公式アカウント」= 企業 = 人間味がない = フォローしたくない。

修正案:
✅ 「外食の栄養データを調べまくってる人。20チェーン500メニューのPFC全部まとめた → tabenavi.jp ／ジム週3 ／サイゼリヤの若鶏のグリルで生きてる」

**なぜこれが良いか:**
- 「公式アカウント」ではなく「人」に見える
- 具体的な趣味・生活が見える（ジム週3、サイゼリヤ）
- フォローする理由が明確（外食の栄養データを知れる）

## フェーズ1: フォロワー100 → 500人

### リプライを続けつつ、投稿を再開

フォロワー100人を超えたら、投稿が届き始める。
ここで初めて「コンテンツ投稿」を再開する。

### 投稿パターン（週5-7本、反応を見て調整）

**パターン1: 数値バズ（週2回）**
```
マクドナルドで一番タンパク質コスパがいいメニュー知ってる？

エグチ。¥200でP20.7g。
1gあたり9.7円。

プロテインバーより安い。
```

**パターン2: 比較（週2回）**
```
同じ500円ランチ

サイゼリヤ 若鶏のグリル
→ P35.3g / 514kcal

松屋 牛めし並盛
→ P22.8g / 709kcal

タンパク質1.5倍、カロリー200kcal低い。
筋トレ後ならサイゼリヤ一択。
```

**パターン3: 意外な事実（週1回）**
```
ケンタッキーのオリジナルチキン、
実は揚げ物の中では優秀。

1本: P18.3g / 237kcal

同カロリーのポテト(M)と比べて
タンパク質14g多い。

ジムの後にKFC、全然あり。
```

### 反応の測定

各投稿の「いいね数」「リプライ数」「プロフィールクリック数」を記録。
最も反応が良かったフォーマットを繰り返す。

## フェーズ2: フォロワー500 → 1,000人

### 引用RT + コラボ

- バズっている筋トレ・ダイエット投稿を見つけたら、データ付きで引用RT
- 「このメニューのPFC調べました → P○○g / F○○g / C○○g / ¥○○○」
- フォロワー1,000-5,000人のアカウントに直接メンションして質問に答える
