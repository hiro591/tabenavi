# たべなび コンテンツ投稿ガイド

> 30日分のnote記事 + X投稿を最短で予約セットする手順書

---

## 1. note.com 予約投稿の手順（所要時間: 約90分で30日分完了）

### 初回セットアップ
1. [note.com](https://note.com) でアカウント作成
2. プロフィール設定:
   - **名前**: たべなび｜外食の栄養が分かるアプリ
   - **自己紹介**: 外食しながらカラダづくり。20チェーン・500メニューの栄養データが無料で使えるWebアプリ「たべなび」の公式アカウントです。 https://tabenavi.jp
   - **アイコン**: たべなびのロゴ or アプリのスクリーンショット
   - **ヘッダー画像**: アプリ画面のモックアップ

### 記事の予約投稿手順（1記事3分）
1. note.com にログイン
2. 右上の「投稿」→「テキスト」を選択
3. `note_30days_part1.md` から Day 1 の記事をコピー
4. タイトルを入力、本文をペースト
5. ハッシュタグを設定
6. 右上の「...」→「予約投稿」を選択
7. 投稿日時を設定（例: 2026/3/21 12:00）
8. 「予約する」をクリック
9. Day 2〜30 を繰り返す

### ファイルの場所
- Day 1-15: `marketing/note_30days_part1.md`
- Day 16-30: `marketing/note_30days_part2.md`

### 投稿スケジュール
- 毎日12:00に1記事（ランチ前が最もPVが伸びる時間帯）
- 開始日: 2026/3/21（土）
- 終了日: 2026/4/19（日）

## 2. X（Twitter）予約投稿の手順（所要時間: 約60分で30日分完了）

### 初回セットアップ
1. [x.com](https://x.com) でアカウント作成（@tabenavi_jp 推奨）
2. プロフィール設定（`x_content_30days_v2.md` 冒頭に記載あり）
3. 固定ツイートを設定

### 予約投稿の方法

#### 方法A: X公式の予約機能（無料）
1. x.com で投稿画面を開く
2. ツイート本文をコピペ
3. カレンダーアイコン（📅）をクリック
4. 日時を設定して「予約設定」
5. 30日分繰り返す

#### 方法B: Buffer（無料プランで月30投稿まで）
1. [buffer.com](https://buffer.com) でアカウント作成
2. Xアカウントを連携
3. 投稿スケジュールを設定（毎日12:00）
4. 30日分のツイートを一括追加

### ファイルの場所
- `marketing/x_content_30days_v2.md`

### 投稿スケジュール
- 毎日12:00に1投稿
- 開始日: 2026/3/21（土）
- 終了日: 2026/4/19（日）

## 3. 効果測定（週1回、5分）

### 確認すること
| 指標 | ツール | 目標 |
|------|--------|------|
| サイト訪問数 | Vercel Analytics | 週100+ |
| 検索表示回数 | Google Search Console | 週1,000+ |
| note PV | note ダッシュボード | 記事あたり100+ |

| 会員登録数 | Supabase Dashboard | 週10+ |

### 改善アクション
- **noteでPVが高い記事** → 同じテーマで深掘り記事を追加
- **XでRT/いいねが多い投稿** → 同じフォーマットで量産
- **Search Consoleで表示されているキーワード** → そのキーワードの記事を追加
