> 目的：tabenavi.jp/signup への登録数を最大化する

> 作成日：2026-03-18

## 1. キャンペーンセットアップガイド

### 1-1. X Ads アカウント開設

1. [ads.x.com](https://ads.x.com) にアクセス
2. tabenavi の X アカウントでログイン
3. 「広告を作成」をクリック
4. 国：日本、タイムゾーン：Asia/Tokyo、通貨：JPY を設定
5. 支払い方法（クレジットカード）を登録

### 1-2. キャンペーン作成手順

1. **キャンペーン目的を選択**：「ウェブサイトのトラフィック」（Website traffic）
2. **キャンペーン名**：`tabenavi_signup_test_v1`（日付やバリエーションを含めると管理しやすい）
3. **日予算を設定**：¥1,000/日（初期テスト期間は5日間 = ¥5,000）
4. **開始日・終了日**：テスト期間を5日間に設定
5. **ペーシング**：「標準配信」（Standard delivery）を選択

### 1-3. Website Card の設定

1. 遷移先 URL：`https://tabenavi.jp/signup`
2. UTM パラメータを付与：`?utm_source=x&utm_medium=paid&utm_campaign=signup_test_v1&utm_content={ad_variation}`
3. Card 画像：1200×628px の OGP 画像を用意（アプリのスクリーンショット or 訴求ビジュアル）

## 4. 入札戦略（Bidding Strategy）

### 4-1. 初期設定

| 項目 | 設定値 |
|------|--------|
| 入札タイプ | 自動入札（Auto bid） |
| 最適化目標 | リンククリック（Link clicks） |
| 日予算 | ¥1,000 |
| 総予算 | ¥5,000（テスト期間） |

### 4-2. 目標指標

| 指標 | 目標値 |
|------|--------|
| CPC（クリック単価） | ¥20〜50 |
| CTR（クリック率） | 0.5% 以上 |
| CPA（登録単価） | ¥100〜300 |
| CVR（クリック→登録） | 10% 以上 |

### 4-3. テスト期間後の入札調整

- CPC が ¥50 を超える場合 → クリエイティブの見直しを優先
- CPC が ¥20 以下で安定 → 手動入札（Maximum bid）に切り替えて ¥30 上限で設定し、コスト効率を最適化
- 十分なデータ（100クリック以上）が溜まってから判断する

### 5-2. コンバージョンイベントの設定

以下のイベントを X Ads Manager で作成：

| イベント名 | トリガー | 設定方法 |
|-----------|---------|---------|

すべての広告リンクに以下の UTM を付与：

```

&utm_campaign=signup_test_v1

```

Google Analytics（または利用中のアナリティクスツール）と連携し、流入〜登録〜利用の一気通貫で計測する。

### 5-4. 週次最適化サイクル

**毎週月曜日に以下を確認・実施：**

1. **データ確認**（30分）
   - 各クリエイティブの CPC / CTR / CPA を比較
   - 時間帯別・曜日別のパフォーマンスを確認
   - ターゲティング別（興味関心 vs キーワード）の成果を比較

2. **アクション決定**（15分）
   - 成果の悪いクリエイティブを停止
   - 成果の良いクリエイティブの予算を増額
   - 新しいクリエイティブのテスト投入を検討

3. **レポート記録**（15分）
   - 主要 KPI をスプレッドシートに記録
   - 前週比の変化を記録
   - 次週のアクションプランを記載

## 6. スケーリングルール

### 6-1. 判定基準と対応アクション

テスト期間終了後、CPA（登録単価）を基準にスケーリングを判断する。

#### CPA < ¥200 の場合：スケールアップ

- 日予算を **20% ずつ段階的に増額**（例：¥1,000 → ¥1,200 → ¥1,440）
- 2〜3日ごとに CPA を確認し、悪化していなければさらに増額
- 成果の良いクリエイティブを中心に配信を集中
- 新しいキーワードや興味関心カテゴリの追加テスト

#### CPA ¥200〜500 の場合：クリエイティブ改善

- 予算は維持、クリエイティブの A/B テストを継続
- 以下を順番にテスト：
  1. 広告文のコピーを変更（訴求軸を変える）
  2. Card 画像を変更（スクリーンショット vs イラスト vs 写真）
  3. ターゲティングの絞り込み（キーワードのみ / 興味関心のみ）
  4. 配信時間帯の限定（昼12〜13時、夜20〜23時 など）

#### CPA > ¥500 の場合：一時停止・再検討

- キャンペーンを **一時停止**
- 以下を見直す：
  1. LP（tabenavi.jp/signup）の離脱率・CVR を確認
  2. ターゲティングが広すぎないか検証
  3. 広告とLPのメッセージの一貫性を確認
  4. 競合の広告をリサーチ
- 改善施策を反映してから再開

### 6-2. スケーリングの上限目安

| フェーズ | 日予算 | 月予算目安 | 条件 |
|---------|--------|-----------|------|
| テスト | ¥1,000 | ¥5,000（5日間） | 初回 |
| 小規模運用 | ¥2,000〜3,000 | ¥60,000〜90,000 | CPA < ¥300 |
| 本格運用 | ¥5,000〜10,000 | ¥150,000〜300,000 | CPA < ¥200 安定 |
| 拡大期 | ¥10,000〜 | ¥300,000〜 | CPA < ¥150 安定 + LTV 確認済 |
