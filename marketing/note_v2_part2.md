## Day 16: 週5外食生活の1週間メニュー全部見せます

**投稿予定日**: 2026年4月5日
**ハッシュタグ**: #外食ダイエット #1週間メニュー #PFC管理 #食事記録 #カロリー計算

「外食ダイエットって具体的に何食べてるの？」

これ、マジでよく聞かれるんだよね。

だから今日は、僕の実際の1週間の食事をぜんぶ公開します。カロリーもPFCも全部。隠しません。

まず前提として、僕の1日の目標カロリーは約1,800kcal。タンパク質は120g以上、脂質は50g以下を意識してる。体重67kg、デスクワーク中心のITエンジニアとしては、これくらいが維持ラインなんだよね。

じゃあいくよ。

**月曜日**
- 朝: セブンのサラダチキン(125kcal/P27g) + おにぎり1個(180kcal)
- 昼: 松屋の牛めし並(709kcal/P20g/F25g)
- 夜: 大戸屋のしまほっけ定食(約620kcal/P35g/F18g)
- 合計: 約1,634kcal / P82g / F43g

月曜は控えめにスタート。週末にちょっと食べすぎた罪悪感があるから、夜は魚系にしてる。

**火曜日**
- 朝: ファミマのプロテインバー(183kcal/P15g) + ブラックコーヒー
- 昼: サイゼリヤの若鶏のグリル ディアボラ風(480kcal/P34g/F22g) + スープ(30kcal)
- 夜: すき家の牛丼ライト(415kcal/P25g/F18g)
- 合計: 約1,108kcal / P74g / F40g

火曜はちょっと少なすぎた。正直、夜にプロテインバー追加した。合計1,291kcal。こういう日もある。

**水曜日**
- 朝: なし（寝坊）
- 昼: マクドナルドのチキンクリスプ(345kcal/P14g/F16g) + サイドサラダ(10kcal)
- 夜: やよい軒のしょうが焼き定食(約780kcal/P35g/F28g)
- 間食: ギリシャヨーグルト(100kcal/P12g)
- 合計: 約1,235kcal / P61g / F44g

水曜は寝坊パターン。朝抜きは良くないってわかってるけど、たまにやる。正直に書く。

**木曜日**
- 朝: ローソンのたまごサンド(300kcal/P10g/F17g)
- 昼: 丸亀製麺のかけうどん並(305kcal/P8g/F1.5g) + かしわ天(200kcal/P12g)
- 夜: CoCo壱のポークカレー(755kcal/P15g/F20g) ※ご飯200g指定
- 合計: 約1,560kcal / P45g / F38.5g

木曜はタンパク質が足りなかった。カレーうまいけど、タンパク質少ないんだよね。反省日。

**金曜日**
- 朝: セブンのゆで卵2個(152kcal/P13g) + バナナ(86kcal)
- 昼: サブウェイのローストチキン(282kcal/P20g/F3.5g)
- 夜: ケンタッキーのオリジナルチキン2ピース(474kcal/P37g/F29g) + コールスロー(92kcal)
- 合計: 約1,086kcal / P70g / F32.5g

金曜は攻めの低カロリー。夜にケンタッキー食べてもこの数字。これが外食ダイエットの醍醐味。

**1週間の平均**
- カロリー: 約1,361kcal/日
- タンパク質: 約66g/日
- 脂質: 約40g/日

正直、タンパク質がもうちょい欲しいところ。でも1,800kcal目標に対してこの数字なら、週末に少し余裕がある計算。

ちなみにこの記録、全部たべなびで管理してる。チェーン店名で検索してメニュー選ぶだけだから、記録は1食30秒くらい。自炊してないからこそ、記録が楽なんだよね。

「外食＝不健康」って思い込みを壊すのが、このシリーズの目的。来週もまた公開するかも。需要あったら教えてください。

## Day 17: 飲み会で2000kcal摂った翌日、体重計に乗った話

**投稿予定日**: 2026年4月6日
**ハッシュタグ**: #飲み会 #ダイエット失敗 #体重管理 #リカバリー #外食ダイエット

先週の金曜日、会社の飲み会に行った。

居酒屋で3時間。ビール4杯、唐揚げ、ポテトフライ、シメのラーメン。

帰ってからたべなびで概算を記録してみたら、出た数字が**約2,300kcal**。

いや、シメのラーメンだけで800kcalあるんだよ。知ってたけど食べたんだよ。人間ってそういう生き物なんだよね。

翌朝、恐る恐る体重計に乗った。

**68.4kg。**

前日が67.1kgだったから、+1.3kg。

「終わった......」って思った？　僕も思った。

でもね、ここで大事な知識がある。

**脂肪1kgを増やすには約7,200kcalの余剰が必要。**

僕の1日の消費カロリーが約2,000kcalだとすると、2,300kcal摂っても余剰は300kcal。脂肪換算でたった約40g。

じゃあ+1.3kgの正体は何かって言うと、ほとんどが**水分**と**食べ物の重量**。アルコールは体に水分を溜め込むし、塩分の多いおつまみも同じ。体の中の「水」が増えただけ。

実際、翌日と翌々日に普通の食事に戻したら、こうなった。

- 土曜: 68.4kg → 普通に1,600kcalの食事
- 日曜: 67.8kg → 普通に1,700kcalの食事
- 月曜: 67.3kg

はい、ほぼ元通り。

これ知ってると、飲み会の翌日にパニックにならない。「あー水分だな」って冷静でいられる。

僕のリカバリー戦略はシンプルで、3つだけ。

**1. 翌日は「普通に」食べる**
断食とか極端な制限はしない。普段通りの1,600〜1,800kcalに戻すだけ。

**2. 水をいつもより多く飲む**
アルコールで脱水してるし、塩分を排出するためにも水が必要。2リットル以上意識して飲む。

**3. 体重計には乗るけど、一喜一憂しない**
数字は見る。でも「3日後の体重」で判断する。1日の数字に意味はない。

ダイエット中に飲み会を断り続けるのは現実的じゃない。付き合いもあるし、単純に楽しいし。

大事なのは「飲み会に行った自分を責めない」こと。1回の飲み会で3ヶ月の努力は崩れない。データがそう言ってる。

翌日の体重計が怖い人、この記事をブックマークしておいてほしい。「大丈夫、水分だから」って思い出せるように。

## Day 18: コンビニのサラダチキンに飽きた筋トレ民へ

**投稿予定日**: 2026年4月7日
**ハッシュタグ**: #サラダチキン #高タンパク #筋トレ飯 #外食 #タンパク質

サラダチキン、何個食べた？

僕はこの半年で推定150個以上食べた。プレーン、ハーブ、スモーク、レモン、タンドリー......。全フレーバー制覇した。

そして、ついに限界が来た。

パッケージを見るだけで食欲が消える現象。これ、筋トレ民あるあるだよね？

でもタンパク質は摂りたい。サラダチキン以外で。外食で。

というわけで、僕が実際にサラダチキンの代わりに食べてる高タンパク外食メニューを紹介する。全部リアルに食べてるやつ。

**1. ケンタッキー オリジナルチキン（237kcal / P18.3g / F14.7g）**
意外でしょ？　フライドチキンなのにタンパク質18g。2ピース食べれば36g。サラダチキンより満足度が圧倒的に高い。衣を少し外せば脂質もカットできる。

**2. サイゼリヤ 若鶏のグリル ディアボラ風（480kcal / P34g / F22g）**
500円でタンパク質34g。コスパ最強。しかも普通にうまい。僕は週1で食べてる。

**3. すき家 牛丼ライト（415kcal / P25g / F18g）**
ご飯の代わりに豆腐が入ってるやつ。糖質カットしながらタンパク質25g。牛丼食べたい欲も満たせる。

**4. 松屋 ネギたっぷり旨辛ネギたま牛めし（約750kcal / P25g / F25g）**
カロリーは高めだけど、卵追加でタンパク質ブースト。味変としては最高。

**5. サブウェイ ローストチキン（282kcal / P20g / F3.5g）**
脂質3.5g。これはバグ。野菜もたっぷり摂れるし、サラダチキンの上位互換だと思ってる。

**6. 大戸屋 しまほっけの炭火焼き定食（約620kcal / P35g / F18g）**
魚でタンパク質35g。DHAも摂れる。ちょっと値段は張るけど、「ちゃんとした食事してる感」がすごい。

**7. なか卯 親子丼（約670kcal / P28g / F15g）**
卵と鶏肉のダブルタンパク質。和食の安心感。

**8. コンビニのサラダフィッシュ（約100kcal / P15g）**
サラダチキンに飽きたならまずこれ。魚版サラダチキン。味もけっこう良い。

ポイントは「タンパク質だけ」で選ばないこと。脂質とのバランス、そして何より**「飽きないこと」**が継続のカギ。

僕はたべなびでメニューを検索するとき、タンパク質順にソートして上から見ていくんだけど、これやると「え、このメニューこんなにタンパク質あったの？」って発見がある。

サラダチキンだけがタンパク質じゃない。外食の選択肢は思ってるより広い。

飽きたら逃げていい。逃げ先はたくさんあるから。

## Day 19: "何食べてるの？"って聞かれて答えに困る問題

**投稿予定日**: 2026年4月8日
**ハッシュタグ**: #ダイエット中の会話 #外食ダイエット #食事管理 #ダイエッターあるある #PFC

「最近痩せたよね。何食べてるの？」

この質問、ダイエット中に一番困る。

なぜかって言うと、答えが「普通に外食」だから。

「マクドナルドとか牛丼とか食べてるよ」って言うと、「え？　それで痩せるの？」って顔される。

かと言って「PFCバランスを意識して、1日のタンパク質を120g以上、脂質を50g以下に......」とか説明し始めると、相手の目が死ぬ。

だから最近は「カロリー見て選んでるだけだよ」って言うようにしてる。

嘘じゃない。でも全部は伝わらない。

76kg→67kgに落とした9kgの裏側には、もうちょっと色々ある。

**やってること、実はシンプル**

1. 食べる前にカロリーを確認する（30秒）
2. タンパク質が多いメニューを選ぶ（意識するだけ）
3. 食べたものを記録する（1食30秒）

これだけ。本当にこれだけ。

でもこの「これだけ」を説明するのが、意外と難しい。

「ジムは？」→ 週2で行ってるけど、痩せたのは食事管理のおかげ。
「サプリは？」→ プロテイン飲んでるけど、それは筋肉のため。
「糖質制限？」→ してない。うどんもカレーも食べてる。

全部「違う、そうじゃない」なんだよね。

一番近い答えは、**「知識で食べてる」**ってこと。

かけうどんが305kcalで脂質1.5gってこと。
サイゼリヤのディアボラ風がタンパク質34gってこと。
牛丼並盛のカロリーがチェーンによって100kcal違うこと。

この知識があるだけで、「何を食べるか」の選択が変わる。

我慢してるわけじゃない。鶏むね肉とブロッコリーだけ食べてるわけでもない。

**知ってるから、選べる。**

これが僕の答え。

でも飲み会で聞かれたときにこれ全部説明するのは無理だから、「アプリで管理してるだけだよ」って答えてる。たべなびっていうやつ。自分で作った。

「え、自分で作ったの？」ってなって、そこからダイエットの話じゃなくてアプリの話になるのは、ITエンジニアあるある。

## Day 20: 外食ダイエット3ヶ月目。体重より変わったもの

**投稿予定日**: 2026年4月9日
**ハッシュタグ**: #ダイエット3ヶ月 #体の変化 #外食ダイエット #メンタル #生活改善

外食ダイエットを始めて3ヶ月が経った。

体重は76kg→67kg。9kg減。

でも今日は体重の話じゃなくて、**体重以外で変わったこと**を書きたい。

数字に表れない変化のほうが、実は人生への影響がデカいんだよね。

**1. 肌がきれいになった**

これ、マジで実感してる。

脂質を抑えるようになってから、おでこのテカリと吹き出物が明らかに減った。以前は毎朝あぶらとり紙を使ってたけど、今はほぼ使わない。

友達にも「肌きれいになった？」って言われた。ダイエットしてるとは言ってないのに。

脂質の1日摂取量を50g以下にしただけ。スキンケアは変えてない。

**2. 睡眠の質が上がった**

以前は夜中に何度か目が覚めてた。今はほぼ朝までぐっすり。

理由はたぶん、夜遅くにドカ食いしなくなったから。以前は23時にカップラーメンとか食べてたんだよね。今は夕食をちゃんと管理してるから、寝る前にお腹が重い感覚がない。

睡眠アプリのスコアが、平均65→78になった。地味にうれしい。

**3. メンタルが安定した**

これが一番大きいかもしれない。

ダイエット前は「また食べすぎた」「もう無理」「明日から頑張ろう」の無限ループだった。自己嫌悪の塊。

今は「今日は1,650kcalだった。いい感じ」とか「ちょっとオーバーしたけど、明日で調整すればOK」って思える。

数字で管理してるから、感情に振り回されない。「食べすぎた」が「200kcalオーバーした」に変わるだけで、こんなにメンタルが楽になるとは思わなかった。

**4. 食への「意識」が変わった**

前は「安い」「近い」「楽」で店を選んでた。

今は「タンパク質が摂れる」「PFCバランスがいい」が選択基準に加わった。

面白いのは、これが「制限」じゃなくて「選択肢の拡大」だったこと。知識が増えた分だけ、選べるメニューが増えた。

「今日はタンパク質足りてるから、好きなもの食べよう」って判断ができるようになった。自由度が上がったんだよね。

**5. 「自分をコントロールできてる感」**

これが地味に一番うれしい。

体重って、コントロールできないものだと思ってた。体質とか遺伝とか、そういうもので決まるんだと。

でも3ヶ月間、データを取り続けてわかった。食べたものと体重は、ちゃんと連動する。コントロールできる。

この「自分で自分をコントロールできてる」って感覚が、仕事にも趣味にもいい影響を与えてる気がする。

9kgの減量も嬉しいけど、こういう「数字に表れない変化」のほうが、長期的には価値があると思ってる。

たべなびで記録を始めたのがきっかけだけど、変わったのはアプリのおかげじゃなくて、自分の意識のおかげ。アプリはあくまでツール。使うのは自分。

体重計に乗るのが怖い人、まずは「記録する」ことから始めてみてほしい。体重より先に、もっと大事なものが変わるから。

## Day 21: 丸亀製麺のうどん、実はダイエット向きだった

**投稿予定日**: 2026年4月10日
**ハッシュタグ**: #丸亀製麺 #うどんダイエット #低脂質 #カロリー #外食ダイエット

「ダイエット中にうどん？　炭水化物のかたまりじゃん」

これ、僕も思ってた。

でもデータを見て考え方が変わった。

丸亀製麺のかけうどん（並）。

**305kcal。タンパク質8.5g。脂質1.5g。**

脂質1.5g。

いや、これバグでしょ。

比較してみてほしい。
- マクドナルド チキンクリスプ: 345kcal / F16g
- 吉野家 牛丼並盛: 635kcal / F20.4g
- CoCo壱 ポークカレー: 755kcal / F20g

かけうどん、圧倒的に低カロリー・低脂質。

「でも炭水化物多いでしょ？」

うん、多い。糖質は約60g。

でもね、ここが大事なポイント。

**ダイエットで最も重要なのは「総カロリー」であって、糖質の量じゃない。**

305kcalのうどんと、500kcalのサラダボウル、どっちが痩せるかって言ったら、305kcalのうどん。カロリー収支がすべて。

もちろん、PFCバランスも大事。だから僕はうどんだけじゃなくて、タンパク質を補うために工夫してる。

**僕の丸亀製麺オーダー**

- かけうどん並（305kcal / P8.5g / F1.5g）
- かしわ天（約200kcal / P12g / F10g）
- 合計: **約505kcal / P20.5g / F11.5g**

これで500kcalちょい。ランチとしては超優秀。

天ぷらは1個だけ。ここ大事。

丸亀の天ぷらって、つい2個3個取っちゃうじゃない？　あれやると一気に800〜1000kcalコースになる。天ぷらコーナーの誘惑は、ダイエッターにとってラスボス級。

**避けるべきは「天ぷら祭り」**

- 野菜かき揚げ: 約240kcal / F14g
- えび天: 約110kcal / F5g
- さつまいも天: 約170kcal / F7g

全部乗せたら天ぷらだけで500kcal超え。うどんの意味がなくなる。

逆に言えば、**天ぷらさえコントロールすれば丸亀製麺は最強のダイエット飯**になる。

ちなみに、釜揚げうどんも同じくらいのカロリー。ぶっかけも並なら350kcal前後。どのうどんを選んでも、ベースが低カロリーなのは変わらない。

たべなびで丸亀製麺のメニューを検索すると、天ぷら含めて全メニューのカロリーが出る。天ぷらコーナーの前で「これ何kcalだっけ？」って確認するだけで、だいぶ変わるよ。

うどんは敵じゃない。敵は天ぷらコーナーの誘惑。

## Day 22: スタバで100kcal以下にする方法を編み出した

**投稿予定日**: 2026年4月11日
**ハッシュタグ**: #スタバ #カスタマイズ #低カロリー #ダイエット #カフェ

スタバが好きだ。

でもスタバのドリンクって、何も考えずに頼むとカロリーがえぐいんだよね。

キャラメルフラペチーノのTall、**322kcal**。

これ、牛丼のミニ盛くらいのカロリーがある。飲み物で。

「ダイエット中はスタバ行けないな......」って思ってた時期もあった。

でもカスタマイズを研究したら、100kcal以下で全然楽しめることに気づいた。

今日は僕が実際にやってる注文を全部公開する。

**注文1: アイスコーヒー（無脂肪ミルク追加）— 約15kcal**

一番シンプル。ドリップコーヒーのアイスに、無脂肪ミルクを追加（無料）。これで十分うまい。ブラックが苦手な人はこれ。

**注文2: カフェミスト（無脂肪ミルク変更）— 約60kcal**

カフェミストは通常のミルクだと約120kcal。無脂肪ミルクに変更するだけで半分になる。変更は無料。温かいのが飲みたい日はこれ。

**注文3: アイスティー（パッションティー）— 0kcal**

はい、ゼロ。お茶だから当たり前なんだけど、スタバに来て0kcalで帰れるのは精神的に良い。甘さが欲しければシロップ少なめで頼める。

**注文4: ソイラテ（シロップ抜き）— 約95kcal**

豆乳ベースのラテ。シロップを抜いてもらうと100kcal以下に収まる。豆乳の甘みだけで十分おいしい。

**注文5: コールドブリュー（無脂肪ミルク追加）— 約10kcal**

コールドブリューは水出しだからすっきりしてる。無脂肪ミルクを足して約10kcal。夏場はこれ一択。

**カスタマイズの3大ルール**

ルール1: **ミルクは「無脂肪」に変更**
通常のミルク→無脂肪ミルクでカロリー約40%カット。無料でできる。

ルール2: **シロップは「少なめ」か「抜き」**
バニラシロップ1ポンプで約20kcal。2ポンプで40kcal。抜くだけでこの分がゼロになる。

ルール3: **ホイップは「なし」**
ホイップクリームは約89kcal。フラペチーノのホイップを抜くだけで約90kcalカット。でかい。

この3つを組み合わせると、フラペチーノ系でも200kcal以下に持っていける。

ちなみに、カスタマイズは店員さんに普通に伝えればOK。「無脂肪ミルクに変更で、シロップ少なめ、ホイップなしで」って言えばやってくれる。恥ずかしくない。みんなやってる。

僕はスタバに行くとき、たべなびでスタバのメニューカロリーをざっと確認してから行く。「今日はあと300kcal余裕あるから、ちょっと贅沢してソイラテにしよう」みたいな判断ができる。

## Day 23: ダイエットに失敗する人の共通点、5つ見つけた

**投稿予定日**: 2026年4月12日
**ハッシュタグ**: #ダイエット失敗 #ダイエットあるある #食事管理 #継続のコツ #外食ダイエット

偉そうなタイトルだけど、全部僕のことです。

76kgから67kgに落とすまでに、何回失敗したか覚えてない。少なくとも5回はダイエットを「始めて」「やめて」を繰り返した。

その失敗を振り返って、共通点を見つけた。過去の自分への手紙みたいなもんだと思って読んでほしい。

**共通点1: 「明日から本気出す」で先延ばしにする**

これ、僕の得意技だった。

月曜から始めよう → 月曜の昼にラーメン食べる → 「もう今週は無理だから来週から」

この無限ループ。

今思うと、「完璧な開始日」なんて存在しない。今日の次の1食から意識するだけでいい。

**共通点2: いきなり極端な制限をする**

「1日1000kcalに抑える！」「糖質ゼロ！」「夜ご飯抜く！」

全部やった。全部3日以内に挫折した。

人間の意志力には限界がある。1日200〜300kcal減らすだけで十分。月に1kgずつ落とすくらいがちょうどいい。

僕は1,800kcal目標で始めて、そこから徐々に調整した。いきなり1,200kcalとかやってたら絶対続かなかった。

**共通点3: 記録しない**

「だいたいこれくらいかな」で食べてると、だいたいオーバーする。人間の「だいたい」は信用できない。

研究でも、人は自分の食事量を平均20〜30%過少評価するって言われてる。つまり「1,500kcalくらいかな」と思ったら、実際は1,800〜1,950kcal食べてる。

記録するだけで、この「認知の歪み」が補正される。記録は最強のダイエットツール。僕がたべなびを作った理由の1つがこれ。

**共通点4: 「食べちゃった＝失敗」と思い込む**

飲み会で食べすぎた。お菓子を食べちゃった。ラーメンのスープ全部飲んだ。

それを「失敗」だと思って、「もういいや」って投げ出す。

これ、「all or nothing思考」っていうやつ。完璧にできないなら意味がない、っていう考え方。

でも実際は、1回食べすぎても翌日と翌々日で調整すれば、週単位のカロリーはちゃんと収まる。**「1食の失敗」は「ダイエットの失敗」じゃない。**

**共通点5: 体重だけを見る**

毎朝体重計に乗って、昨日より増えてたら落ち込む。減ってたら喜ぶ。

体重は水分や便通で1〜2kg簡単に変動する。日単位の体重に意味はない。

僕は週平均で見るようにしてから、メンタルがめちゃくちゃ安定した。月曜に67.5kgでも金曜に66.8kgなら、その週は順調。

**まとめると**

失敗パターンの根っこは、全部「完璧を求めすぎる」こと。

ダイエットは70点で十分。週に5日ちゃんとできてれば、残り2日は好きなもの食べていい。

この「70点主義」にしてから、僕のダイエットは初めて続いた。

完璧じゃなくていい。続けられることが、一番大事。

## Day 24: 体重67kgをキープして3ヶ月。維持の方が難しい

**投稿予定日**: 2026年4月13日
**ハッシュタグ**: #体重維持 #ダイエット維持期 #リバウンド防止 #食事管理 #外食ダイエット

9kgの減量に成功。やった。ゴール。おめでとう自分。

減量中は「痩せる」っていう明確なゴールがある。体重計の数字が下がるたびにモチベーションが上がる。目に見える成果がある。

でも維持期は違う。

「現状維持」が目標。体重計に乗って67kgだったら「よし」。67.2kgでも「よし」。別に嬉しくはない。だって変わってないんだから。

**モチベーション、どこ？**

最初の1ヶ月は特にキツかった。

「もう食事管理しなくていいんじゃない？」って悪魔がささやく。「67kgになったんだから、好きなもの食べていいでしょ」って。

実際、少し気を抜いたら2週間で68.5kgまで戻った。1.5kgのリバウンド。

「あ、これ放置したら全部戻るやつだ」

そこで目が覚めた。

**維持期に僕がやってること**

**1. カロリー管理は「ゆるく」続ける**

減量中は1日1,500〜1,600kcalだった。維持期は1,800〜2,000kcalに上げた。

厳密に毎食記録はしてないけど、1日1回はたべなびを開いて「今日どれくらい食べたかな」って振り返る。これだけで大きく脱線しない。

毎日乗ると数字に振り回される。だから週1回、同じ曜日の朝に測る。月曜の朝、トイレの後。条件を統一する。

67.5kg以下なら問題なし。68kgを超えたら、その週はちょっと意識的にカロリーを抑える。

僕の場合、ランチは基本的にサイゼリヤのディアボラ風か、サブウェイのローストチキン。この2つをデフォルトにしておくと、考えなくても栄養バランスが整う。

「何食べようかな」と悩む→面倒になる→適当に食べる→カロリーオーバー

この流れを防ぐために、「迷ったらこれ」を決めておく。仕組み化ってやつ。

**4. たまに「チートデイ」を入れる**

月に2〜3回、カロリーを気にしない日を作る。焼肉行ったり、ラーメン食べたり。

これがないと精神的に持たない。維持期はマラソンだから、給水所が必要。

**維持の秘訣は「仕組み化」**

結局、意志力に頼ると負ける。「頑張って維持する」じゃなくて「仕組みで維持する」が正解。

記録する仕組み。基準メニューの仕組み。週1チェックの仕組み。

仕組みさえ作れば、意志力はほとんど使わない。歯を磨くのと同じレベルまで落とし込めたら、もうリバウンドしない。

67kgをキープして3ヶ月。やっと「これ、一生続けられるかも」って思えるようになった。

**5パターンに共通するコツ**

1. **ご飯の量で調整する** — 「少なめ」にするだけで80〜100kcalカット
2. **汁物を活用する** — 50kcal以下で満足度アップ
3. **間食は高タンパク低カロリー** — ゆで卵、ヨーグルト、サラダチキン
4. **1食で完璧を目指さない** — 1日トータルで帳尻を合わせる

これ全部、たべなびで各メニューのカロリーを調べながら組み立てた。外食メニューのカロリーが頭に入ってくると、パターンを作るのが楽しくなってくるんだよね。

1,500kcalは慣れれば全然キツくない。むしろ「何を食べるか選ぶ楽しさ」がある。

## Day 29: 外食ダイエットで学んだ、たった1つの大事なこと

**投稿予定日**: 2026年4月18日
**ハッシュタグ**: #ダイエットの本質 #食べて痩せる #外食ダイエット #知識は武器 #マインドセット

76kg→67kg。

9kgの減量。3ヶ月。完全外食。自炊ゼロ。

この経験を通じて学んだ、たった1つの大事なこと。

**「食べない」じゃなくて「選ぶ」。**

これだけ。本当にこれだけ。

でもこの1つが、僕のダイエット人生を完全に変えた。

思い返すと、過去の失敗は全部「食べない」ダイエットだった。

夜ご飯を抜く。糖質を抜く。揚げ物を抜く。間食を抜く。

抜く、抜く、抜く。

我慢、我慢、我慢。

そして爆発。リバウンド。自己嫌悪。

「食べない」ダイエットは意志力で体をコントロールしようとするアプローチ。でも意志力には限界がある。1日は我慢できても、1週間は無理。1ヶ月なんて絶対無理。

「選ぶ」ダイエットは違う。

マクドナルドに行く。ビッグマック（525kcal）じゃなくてチキンクリスプ（345kcal）を選ぶ。180kcalの差。我慢じゃない。知識に基づく選択。

牛丼屋に行く。特盛（1,013kcal）じゃなくて並盛（635kcal）を選ぶ。ご飯少なめにする。さらに-80kcal。これも我慢じゃない。「並盛で十分満足できる」って知ってるから選べる。

スタバに行く。フラペチーノ（322kcal）じゃなくて無脂肪カフェミスト（60kcal）を選ぶ。カスタマイズの知識があるから、262kcalを「楽しく」節約できる。

**全部、知識の問題。**

かけうどんが305kcalだって知ってれば、「ダイエット中にうどんはダメ」なんて思わない。

KFCのオリジナルチキンがタンパク質18gだって知ってれば、「揚げ物は全部敵」なんて思わない。

サイゼリヤのディアボラ風が500円でタンパク質34gだって知ってれば、「ダイエット中の外食は高くつく」なんて思わない。

知識があれば、選択肢が広がる。選択肢が広がれば、我慢が減る。我慢が減れば、続けられる。

これが「選ぶ」ダイエットの本質。

僕がたべなびを作ったのは、この「知識」を手軽に手に入れるため。

メニュー名で検索するだけで、カロリーとPFCがわかる。知識のハードルを下げたかった。「調べるのが面倒」で諦める人を減らしたかった。

ダイエットの敵は、食べ物じゃない。

ダイエットの敵は、「知らないこと」。

知れば、選べる。選べば、変わる。

これが、外食ダイエットで学んだ、たった1つの大事なこと。

あなたの「次の1食」から始めてみてほしい。いつもの店で、いつものメニューのカロリーを、1回だけ調べてみる。

それだけで、何かが変わり始めるから。

## Day 30: これからの僕と、たべなびのこと

**投稿予定日**: 2026年4月19日
**ハッシュタグ**: #たべなび #個人開発 #外食ダイエット #これからの目標 #感謝

30日間、読んでくれてありがとう。

Day 1から今日まで、毎日書いてきた。外食ダイエットのこと、栄養のこと、失敗のこと、成功のこと。

最終日は、これからの話をしたい。

**僕のこれまで**

28歳、ITエンジニア、一人暮らし。

完全外食生活で76kgまで太って、「このままじゃやばい」と思って始めたダイエット。

既存のアプリが外食に対応してなくて、「じゃあ自分で作ろう」って始めたのがたべなび。

3ヶ月で9kg減。67kgをキープして、さらに3ヶ月。

この半年間で、体が変わって、食への意識が変わって、メンタルが変わった。

正直に言うと、最初はたべなびが誰かの役に立つなんて思ってなかった。自分が使えればそれでいい、くらいの気持ちだった。

でもnoteを書き始めて、Xで発信を始めて、少しずつ反応をもらえるようになって。

「使ってます」ってDMをもらって。

「自分だけの問題」だと思ってたことが、「たくさんの人が抱えてる問題」だったんだって気づいた。

**外食中心の生活で、体型を気にしてる人は、思ってるよりずっと多い。**

自炊すればいいのはわかってる。でもできない人がいる。時間がない、料理が苦手、キッチンが狭い、そもそも面倒。理由は色々。

そういう人に「自炊しろ」って言うのは簡単だけど、それじゃ何も解決しない。

「外食のまま、健康になれる方法」を提供したい。それがたべなびの存在意義。

**これからやりたいこと**

**1. メニューデータをもっと増やす**
今は21チェーン + コンビニ3社で500メニュー以上。でもまだまだ足りない。ユーザーさんから「○○のメニューが欲しい」って声をもらうたびに追加してる。目標は1,000メニュー。

**2. もっと使いやすくする**
UIを改善し続ける。「3タップで記録完了」をさらに「2タップ」にしたい。お気に入り機能、食事パターンの保存機能、もっと便利にしたいことがたくさんある。

**3. コミュニティを作りたい**
外食ダイエットをしてる人同士がつながれる場所。「今日サイゼでディアボラ風食べた」「わかる、あれコスパ最強だよね」みたいな会話が生まれる場所。いつか作りたい。

**4. このnoteを続ける**
30日で終わりじゃない。外食ダイエットのネタは無限にある。新メニューのレビュー、季節限定メニューの栄養分析、読者さんからの質問への回答。書きたいことはまだまだある。

**最後に**

僕は特別な人間じゃない。

料理はできない。意志力も弱い。飲み会に行けば食べすぎる。ラーメンのスープも全部飲む（たまに）。

でも、「知識」と「記録」があれば、そんな僕でも体は変えられた。

大事なのは完璧じゃなくて、続けること。

70点でいい。週5日ちゃんとできてれば十分。残りの2日は好きなもの食べよう。

外食は敵じゃない。知識があれば、最強の味方になる。

たべなび（tabenavi.jp）、よかったら使ってみてください。

同じ悩みを持つ人に、届きますように。
