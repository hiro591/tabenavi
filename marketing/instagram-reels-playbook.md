> 作成: 2026-05-11
> 目的: POV / no-narration / lifestyle 系 Reels で App Store install 数 + brand 認知の最大化
> 対象: 3 reels 同日撮影 → 1 週間で順次投稿 → algorithm 学習期間で勝ち筋発見

## 1. なぜ POV / No-Narration Reels が 2026 で勝つか

### Algorithm 視点
- **Watch time が圧倒的**: avg 80%+ retention (talking head 系の 2x)
- **Save 率高い**: 実用 tip 系で「あとで見たい」誘発
- **Share 率高い**: 「自分も同じ悩み」で友達 tag 文化
- **Trending audio integration 容易**: vocal 邪魔せず

### 心理学
- 視聴者が「自分が使ってる」と imagine → 購入意欲 5x (Hubspot 2024)
- 字幕で多言語 / 公共場所 friendly
- 編集効率 (撮り直し最小)

### Algorithm boost 要素
- Native vertical 9:16 (1080×1920)
- 15-30 秒 (Reels sweet spot)
- Trending audio
- Front-loaded captions (front 30% area)
- Loop-friendly ending

## 4. CapCut Step-by-Step Walkthrough

### Pre-edit setup

1. **CapCut app install** (App Store で「CapCut」検索、無料)
2. iPhone と Mac で同 Apple ID なら **iCloud 経由で素材 sync 可**
3. CapCut 起動 → 「+ 新規プロジェクト」

### Step 1: 素材 import (5 分)

1. 「+」 button → 撮影した videos / screen recording 全部選択
2. アスペクト比は **9:16 (TikTok / Reels)** 自動
3. Frame rate **30fps** で OK

### Step 2: Cut & 並び替え (10 分)

1. Timeline で各 clip を cut
   - **長押し → 分割 (split)** で不要部分カット
   - **timing は shot list (0-1s, 1-3s...) に従う**
2. 必要な clip を順番に並べる
3. 各 clip end → 次 clip start の transition は default (smooth)

### Step 3: テキスト overlay (15 分)

1. 各 timing で「テキスト」追加
   - Font: **「ヒラギノ角ゴ ProN」** (iOS native 風)
   - Size: **42-56pt** (mobile で読みやすい)
   - Color: 状況により white / yellow / red
   - Position: **画面中央 30% area** (上下は iOS UI で隠れる)
2. **Animation** 追加:
   - 出現: 「ふわっと」or 「ポップ」
   - 消去: 「すっと」(0.3 秒程度)

### Step 4: 字幕自動生成 (5 分・任意)

1. Timeline 上部の「字幕」 → 「自動生成」
2. 言語: 日本語選択
3. 1-2 分待つ → 自動字幕完成
4. 確認 + 誤字修正
5. Style: 白文字 + 黒影 (iOS native 風)

### Step 5: Trending audio 追加 (10 分)

1. CapCut 内「音楽」 → 「人気」 タブ
2. 各 reel に合う audio 検索:
   - Reel #1: lo-fi chill / drop 系
   - Reel #2: upbeat 議論系
   - Reel #3: gym vibes / lo-fi rap
3. 選んだら「追加」
4. **重要**: drop 瞬間 (vocal entry) を **hook タイミング (1.5-2 秒目)** に合わせる
5. 動画末尾で fade out (0.5 秒)

### Step 6: Trim & polish (5 分)

1. 全体を再生 (preview)
2. 不自然な部分 → trim
3. **総 length 25-32 秒** (Reels の sweet spot)

### Step 7: Export (3 分)

1. 右上 「↑ Export」
2. Resolution: **1080p / 30fps**
3. Watermark: OFF (最重要、CapCut logo を消す)
4. Save to Camera Roll
5. 同時に **Reels 直接 share** option も可

### Step 8: Reels 投稿 (5 分)

1. Instagram app → 「+」 → 「リール」
2. Camera Roll から動画選択
3. **Cover image** 選択 (Hook 0.5 秒目の画像 = 一番 grab する frame)
4. Caption + hashtag 貼り付け
5. **Audio**: CapCut で added audio を Instagram 内 audio に再選択 (algorithm boost のため)
6. Cross-post: TikTok ON も可 (audience overlap)
7. 投稿

## 12. 期待値 + 心構え

### 現実的な期待値

```
1 本目 (Reel #1): 大半は 200-2,000 reach (algorithm 学習中)
2 本目 (Reel #2): 上昇傾向、5,000-15,000 reach 期待
3 本目 (Reel #3): 1-2 本目 data で algorithm が profile を学習、
                  niche 一致で 10,000-50,000 reach 可能性

App Store install:
- 1 本目 = 5-30 install
- 累計 1 ヶ月 = 100-1,000 install (悲観 / 標準)
- バズ 1 発出れば 1 ヶ月 5,000-20,000 install
```

### 心構え

- **最初の 5-10 本は algorithm 学習期間**: 結果出なくて normal
- **続けることが最大の戦略**: 週 3 投稿 × 4 週 = 12 本で本格的な data 収集
- **完璧主義は敵**: 「とりあえず投稿」 > 「完璧を目指して 1 本も出ない」
- **数字で判断、感情で判断しない**: 1 本失敗で諦めない、metric 見て iterate
