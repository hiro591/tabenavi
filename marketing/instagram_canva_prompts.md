# Instagram カルーセル投稿 — Canva用プロンプト集（参考投稿分析済み）

> 参考にしたデザインの特徴:
> - 背景: ベージュ/クリーム系の温かい色（#F5F0E8〜#EDE8DD）
> - 商品: 実物の切り抜き写真を大きく配置
> - フォント: 太いゴシック体（見出し）+ 明朝体ミックス
> - レイアウト: 1枚に情報量多め、商品写真が主役
> - 色アクセント: くすみピンク(#C4898A)やブランドカラー
> - ランキング形式が保存率を上げる

## 投稿1: サイゼリヤ ダイエットメニューランキング

### 1枚目（表紙）— Canvaプロンプト:
```
Instagramのカルーセル投稿の表紙を作成してください。

サイズ: 1080×1350px
背景色: 温かいベージュ (#F5F0E8)
スタイル: 参考画像のような日本のダイエット系Instagramアカウント風

内容:
- 左上にサイゼリヤのロゴ（緑）を配置
- 大きな見出し文字「ダイエット中でも行きたい！」（くすみピンクの帯付き）
- その下に特大文字で「サイゼリヤ 低カロリーランキング」
- 下半分に4つのカテゴリを2×2のグリッドで表示:
  「グリル」「パスタ」「サラダ」「ドリンク」
  各カテゴリに該当するサイゼリヤの料理写真を配置
- 全体的に温かみのあるトーンで、おしゃれなカフェのような雰囲気
- キラキラマーク（✨）を装飾として少し入れる
```

### 2枚目（グリル部門）— Canvaプロンプト:
```
Instagramカルーセルの2枚目を作成してください。

サイズ: 1080×1350px
背景: ベージュ (#F5F0E8)
上部にカテゴリ名「-GRILL- グリル」を装飾枠付きで

ランキング形式で4つのメニューを配置:
1位: 若鶏のグリル — 514kcal（商品写真を大きく、1位の数字を丸で囲む）
2位: ミックスグリル — 478kcal
3位: ディアボラ風ハンバーグ — 542kcal
4位: リブステーキ — 580kcal

各メニューに:
- 切り抜き風の料理写真
- カロリー数値を大きめフォントで
- メニュー名を写真の横に

ランキング順に上から配置し、1位を目立たせる
右下に小さく「※2026年3月時点の情報です」
参考スタイル: スタバ低カロリー一覧のような商品写真ランキングレイアウト
```

## デザインガイドライン（全投稿共通）

### 色
- メイン背景: #F5F0E8（ウォームベージュ）
- サブ背景: #EDE8DD（ライトベージュ）
- アクセント: #C4898A（くすみピンク）
- テキスト: #2D2D2D（ダークグレー）
- 見出し強調: #C0392B（深い赤）/ #FFFFFF（白）
- ポジティブ: #27AE60（グリーン）
- ネガティブ: #E74C3C（レッド）

### フォント
- 見出し: 太いゴシック体（Noto Sans JP Black / Extra Bold）
- 本文: 明朝体 or 標準ゴシック
- 数字（カロリー等）: 極太、サイズ大きめ

### レイアウト原則
- **商品写真が主役**（テキストだけの枠は使わない）
- 1枚目でスクロールを止めさせる（特大文字 or 衝撃的な写真）
- ランキング形式は保存率が高い
- 「痩せる/太る」の比較型は一目で価値がわかる
- 情報密度は高めに（1枚に4-6商品も入れてOK）
- ブランドロゴは必ず入れる（信頼性＋検索性）
