# 案③ 企画書: AI料理写真→PFC自動推定ツール

> **状態**: 未着手 (案①の初収益確認後に検討)
> **作成日**: 2026-04-18

---

## 1. コンセプト

外食やコンビニ食の写真を1枚アップするだけで、AIが自動でカロリー・タンパク質・脂質・炭水化物を推定するシンプルなWebツール。

**仮称**: PFCスナップ (`pfc-snap.app` or `tabenavi.jp/snap`)

---

## 2. なぜこれをやるか

| 観点 | 理由 |
|---|---|
| たべなびとのシナジー | tabenaviから流入 → 写真撮影習慣化 → tabenaviの記録機能に戻る |
| 差別化 | 既存「あすけん」等は会員登録必須・有料。**ログイン不要・写真1枚で即結果**が新規 |
| 拡散性 | 「LINEで友達と食事写真を共有 → カロリー競争」みたいな遊びも生まれうる |
| アフィリ商品の関連性 | 推定結果から「不足しているタンパク質を補う商品」を自然に提案 |

---

## 3. MVP機能スコープ (1〜2日で実装)

### 必須
- 写真アップロード (drag & drop or ファイル選択)
- Anthropic Claude Vision API でPFC推定
- 結果をビジュアル表示 (カロリー、PFCドーナツチャート)
- 「この食事を tabenavi に記録する」ボタン (ディープリンク)

### 任意 (Phase 2)
- 結果のシェアURL生成 (X/LINEシェアボタン)
- 1日の食事ログを匿名で集計 (Cookieベース)
- LINEログインで複数日履歴

## 4. 収益モデル

### Phase 1: 完全無料 + アフィリ間接収益
- 月3-5回まで無料 (匿名Cookie制限)
- 結果画面に「この食事に足りない栄養を補うおすすめ」アフィリ商品を表示
- たべなびへの送客 (本体のサインアップ・記録機能利用)

### Phase 2: フリーミアム
- 無料: 月10回
- プレミアム ¥300/月 (Stripe Subscription)
  - 無制限利用
  - 履歴30日保存
  - 写真→食事日記の自動エクスポート

### 想定 (3ヶ月後)
- 月間ユーザー 5,000人
- 有料転換 1% = 50人 × ¥300 = **月¥15,000**

## 5. コスト試算

### Anthropic Claude Vision API
- claude-haiku-4-5 (Vision対応) を使用
- 1リクエスト約$0.001-0.003 (写真サイズに依存)
- 日本円換算 約¥0.2-0.5/回
- 月10,000リクエスト = **月¥2,000-5,000**

### 結論
- 月数千円のコスト
- アフィリ収益 + プレミアム転換で十分回収可能 (月3,000円稼げばペイ)

## 6. リスクと対応

| リスク | 対応 |
|---|---|
| Vision API精度 (日本食苦手の可能性) | 既存のtabenavi DB (500メニュー) と画像照合で精度補強 |
| API濫用 (1ユーザーが大量呼び出し) | レート制限 (IP × Cookie × Vercel Edge) |
| 競合参入 | tabenaviブランド + 既存SEO資産で先行優位 |
| AI APIコスト爆発 | Cookie閾値超過時はサインアップ要求 + 課金導線 |
