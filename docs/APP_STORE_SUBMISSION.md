## 2. App Name (アプリ名) — 30字以内

### 採用案
```
たべなび 外食ダイエット&カロリー記録
```
**21字** (半角スペース1つ含む)

### 設計理由
- ブランド名「たべなび」を先頭に配置 (検索時の認知度優先)
- 「外食ダイエット」で外食民を即ターゲティング (ASO の核キーワード)
- 「&」記号で「カロリー記録」を補強 (二大ニーズ網羅)
- 30字フルに使わないことで字面の見やすさを優先

### 没案 (参考)
- ❌「たべなび|外食専門のカロリーPFC管理」 → 縦線が App Store では崩れがち
- ❌「外食ダイエット たべなび」 → ブランドが後ろで弱い
- ❌「たべなび - 外食PFC計算アプリ」 → 「PFC」検索ボリューム小

## 5. Description (説明文) — 4,000字以内

### 採用案 (本提出版)
```
外食しかしない社畜のための、栄養管理アプリ「たべなび」

「自炊する時間がない」「コンビニばっかり」「飲み会が多い」
そんな働き盛りの30代が、外食だけでカラダを変えるために作りました。

開発者ヒロは、外食100%の生活で86kg→73kg、1年で13kg減量に成功。
その時に「自分用に欲しかった」アプリを、そのまま形にしました。


■ たべなびでできること

▼ 20チェーン500メニューのPFCを瞬時に検索
セブンイレブン、ファミマ、ローソン、松屋、すき家、吉野家、サイゼリヤ、大戸屋、マック、ケンタッキー、サブウェイ、てんやなど主要外食チェーンを網羅。
全メニューの kcal・タンパク質・脂質・炭水化物を公開データから収録。

▼ 3タップで食事記録
チェーン選択 → メニュー選択 → 量を選んで保存。最短10秒で1食記録完了。
入力の手間を最小化することで、続けられる設計に。

▼ 1日の合計カロリー・PFCを自動計算
朝・昼・晩・間食の合計が一目でわかる。
目標値からの過不足を色で可視化。

▼ 体重推移グラフ
毎日の体重を記録すると、週次・月次でグラフ化。
「今のペースで何kg痩せるか」を予測表示。

▼ 高タンパクメニュー検索
「タンパク質30g以上」「500kcal以下」など条件で全メニューを横断検索。
コンビニで何を買えばタンパク質を稼げるか、迷わず選べる。

▼ お気に入り登録
よく食べるメニューはワンタップで再記録。
「いつものやつ」をすぐ呼び出せる。

▼ チートデイ計算機
「今週どこまで食べてOKか」をPFCバランスから科学的に算出。
飲み会前夜、外食イベント前に必須の機能。


■ こんな人におすすめ

・ 外食率が週5日以上で、自炊する時間がない
・ 過去にダイエットアプリで「メニューを毎回手入力する」のが面倒で挫折した
・ コンビニで「結局何を選べばいいのか」分からなくなる
・ ジムに通っているが、食事管理ができておらず成果が出ない
・ 30代の働き盛り、健康診断で何かしら指摘を受けた
・ 「自炊しろ」と言われても物理的に無理な生活


■ 開発者ヒロのストーリー

3年前、IT 企業勤務、残業月60時間、外食率100%。
健康診断で BMI 28.0、脂肪肝の宣告を受けました。

MyFitnessPal、糖質制限、有酸素運動、プロテイン。
全部試して、全部 3日で挫折。

転機は「数字で食べ物を見る」発想。
サイゼリヤで栄養成分表示を見て気付いたんです。
「外食でも数字さえ握れば、自炊と同じことができる」

そこから 1年、外食 100% のまま 13kg 減量。

その記録と知見を、すべてこのアプリに詰めました。


■ アプリの哲学

✓ 自炊を強制しません。外食のままで成立する設計です。
✓ 特殊なサプリや高額商品の販売は一切ありません。
✓ 「絶対痩せる」「100%」のような誇大広告は使いません。栄養学の基礎理論に基づいた、再現性の高いツールを目指しています。


■ 主な機能

[食事記録] 3タップで完了する高速入力
[PFC計算] 1日の合計を自動計算・可視化
[メニュー検索] 500メニューから条件で横断検索
[体重管理] 推移グラフと予測表示
[お気に入り] よく食べるメニューを保存
[チートデイ] 今週の食べ過ぎ余力を科学的算出
[通知] 朝・夜の記録リマインド (任意設定)


■ 今後の予定

近日中に Premium プラン (月額) を追加予定:
- 月別・年別の詳細レポート
- 体重・PFC の長期トレンド分析
- お気に入りメニュー無制限保存
- 広告非表示

無料版でも基本機能は永続無料です。


■ 利用上の注意

本アプリの情報は栄養学の基礎理論に基づきますが、医学的アドバイスを提供するものではありません。持病をお持ちの方、医師から食事指導を受けている方は主治医にご相談ください。
栄養成分データは各チェーン店の公開データを基に作成していますが、店舗・時期により実際の値と異なる場合があります。
```

- ✅ Guideline 5.1.1 (Privacy): Privacy Policy 完備

### Account Deletion 機能の実装
App Store Guideline 5.1.1(v) で必須要件。
未実装だと 100% リジェクトされる。

実装場所: `/profile` ページ
実装内容:
1. 「アカウント削除」ボタン
2. 確認ダイアログ (取り消し不可の警告)
3. パスワード再入力
4. Supabase の auth.users + 関連テーブルから DELETE
5. 完了後ログアウト → ランディングページへ

技術: Supabase の Server-Side Function or API Route (`/api/account/delete`) で実装。

これは別途 Phase B で実装します (App Store 審査前までに完了必須)。
