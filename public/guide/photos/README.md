# 記事用 実写真の置き場

ここに「自分で撮ったメニューの実写真」を置きます。公式サイトの写真は著作権上NG。

## 手順
1. 外食時にメニューをスマホで撮影（明るい場所・真上か斜め45度・背景はシンプルに）。
2. **Web用にリサイズ**（重要・表示速度＆Vercelコスト対策）:
   - 横 **1200px** 程度、**JPG**、**300KB以下** が目安。
   - Macなら「プレビュー」→ ツール → サイズを調整、or オンラインの squoosh.app など。
3. ファイル名は **下の命名表のid + .jpg** で保存（例: `seven-sanma-shioyaki.jpg`）。
4. ここ（`/public/guide/photos/`）に置く。
5. Claudeに「写真置いた」と伝える → `src/lib/guide/photos.ts` に登録 → 記事に自動表示。

※ 登録するまでは記事に表示されません（壊れない設計）。撮れたものから少しずつでOK。
